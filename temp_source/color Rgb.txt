 Colors::gold 값이 glColor3fv에 전달되는 과정은 C++ 클래스 상속과 메모리 구조를 통해 이루어집니다. 코드를 분석한
  결과를 단계별로 설명해 드리겠습니다.

  1. include/Colors.hpp - 색상 정의

  먼저, Colors::gold는 Colors.hpp 파일에 다음과 같이 정의되어 있습니다.

   1 // include/Colors.hpp
   2
   3 namespace Colors
   4 {
   5     // ... 다른 색상들 ...
   6     inline const RGB gold(255, 223, 0);
   7     // ...
   8 }

   - Colors::gold는 RGB 클래스의 객체(instance)입니다.
   - 생성될 때 웹 표준 RGB 값인 (255, 223, 0)을 정수(integer)로 전달받습니다.

  2. include/RGB.hpp - RGB 클래스 구조

  RGB.hpp를 보면 RGB 클래스가 어떻게 정수 값을 처리하는지 알 수 있습니다.

    1 // include/RGB.hpp
    2
    3 #include "Vector3.hpp"
    4
    5 class RGB : public Vector3<float>
    6 {
    7 public:
    8     // ...
    9     // 정수 RGB 값을 받아서 OpenGL에서 사용하는 실수(float)로 변환하는 생성자
   10     RGB(const int & cr, const int & cg, const int & cb)
   11         : BASE(static_cast<float>(cr) / 255.0f, static_cast<float>(cg) / 255.0f, static_cast<float>(cb) / 255.0f
   12     {}
   13     // ...
   14 };

   - RGB 클래스는 Vector3<float>를 상속합니다. 이는 RGB 객체가 Vector3<float> 객체의 모든 특성을 갖는다는 의미입니다.
   - 정수 값을 받는 생성자는 각 값을 255.0f로 나누어 0.0f ~ 1.0f 사이의 실수(float) 값으로 변환합니다. 이는 OpenGL이
     색상을 처리하는 표준 방식입니다.
   - 따라서 RGB(255, 223, 0)는 내부적으로 Vector3<float>(1.0f, 0.8745f, 0.0f) 와 같은 실수 값으로 저장됩니다.

  3. include/Vector3.hpp - 메모리 구조의 핵심

  RGB가 상속하는 Vector3.hpp는 데이터가 메모리에 어떻게 저장되는지를 보여주는 핵심 부분입니다.

    1 // include/Vector3.hpp
    2
    3 template<typename T>
    4 class Vector3
    5 {
    6 public:
    7     union {
    8         struct { T x, y, z; };
    9         struct { T r, g, b; };
   10         T data[3]; // C-스타일 배열
   11     };
   12     // ...
   13     T & operator [] (const int & ix)
   14     {
   15         return data[ix];
   16     }
   17     // ...
   18 };

   - union 키워드는 여러 멤버 변수가 동일한 메모리 공간을 공유하도록 합니다.
   - struct { T r, g, b; }와 T data[3]가 같은 메모리를 사용하므로, r, g, b 값은 data라는 이름의 float 배열로도 접근할
     수 있습니다.
   - 즉, RGB 객체의 r, g, b 값은 메모리상에 float 3개가 연속적으로 놓인 배열과 같습니다.

  4. DrawFunctions.cpp - OpenGL 함수 호출

  마지막으로 drawFilledStar 함수가 RGB 객체를 어떻게 사용하는지 보겠습니다.

   1 // DrawFunctions.cpp
   2
   3 void drawFilledStar(const RGB & color, const float & outer_radius, const float & inner_radius)
   4 {
   5     // ...
   6     // 색상 설정
   7     glColor3fv(&color[0]);
   8     // ...
   9 }

   - glColor3fv 함수는 float 값 3개를 담고 있는 배열의 시작 주소(포인터)를 인자로 받습니다.
   - color[0]는 Vector3로부터 상속받은 operator[]를 호출하여 color 객체 내부의 data 배열의 첫 번째 요소(data[0])에
     접근합니다.
   - &color[0]는 data[0]의 메모리 주소를 가져옵니다. 이것이 바로 glColor3fv가 요구하는 배열의 시작 주소입니다.

  결론

  Colors::gold에서 glColor3fv 호출까지의 흐름을 요약하면 다음과 같습니다.

   1. `Colors::gold`는 RGB(255, 223, 0)로 생성됩니다.
   2. `RGB` 생성자는 이 정수 값들을 255.0f로 나누어 {1.0f, 0.8745f, 0.0f} 형태의 float 값으로 변환합니다.
   3. 이 float 값들은 부모 클래스인 `Vector3`의 union 구조 덕분에 메모리상에 연속된 float 배열(data[3])로 저장됩니다.
   4. `glColor3fv(&color[0])`는 이 data 배열의 시작 메모리 주소를 가져와 OpenGL에 색상 정보로 전달합니다.

  이러한 방식으로 C++의 객체 지향적인 RGB 클래스가 OpenGL의 C-스타일 함수인 glColor3fv와 완벽하게 호환될 수 있는
  것입니다.
