삼각함수의 덧셈 정리... 공부 해야. 

어떤 점 x, y가 있다. 원점으로 부터 x,y까지의 거리를 r이라 하고 각을  α 라고 함.   
x,y좌표는 각각 x =r * cos α,  y =  r * sin α.  
이 점을 원점에 대해서 θ 만큼 이동. 
변경된 x', y'의 좌표는 x'= r * cos(a +θ ) ,  y' = r * sin(a + θ ). 

--> 덧셈정리를이용해서 변환된 x와 y를 구함. 이때 삼각함수의 덧셈법칙이 사용됨. 
cos(α + θ) = cos(α)cos(θ) - sin(α)sin(θ) //코코싸싸 - 
sin(α + θ) = sin(α)cos(θ) + cos(α)sin(θ)  //싸코코싸 +


x' = r × [cos(α)cos(θ) - sin(α)sin(θ)]
   = r × cos(α) × cos(θ) - r×sin(α) × sin(θ) -->  r x cos(α) = x, r x sin(α) =y  이므로 아래 처럼. 
   = x × cos(θ) - y×sin(θ)  ✅

y' = r × [sin(α)cos(θ) + cos(α)sin(θ)]
   = r × sin(α) × cos(θ) + r×cos(α) × sin(θ)
   = y × cos(θ) + x × sin(θ)
   = x × sin(θ) + y × cos(θ)  ✅

    }
    glPopMatrix(); 
}

< 1. 표준 아이소메트릭> 
- 아이소메트릭은 두번의 회전 y축 중심으로 45도 그 다음 x축 중심으로 35.264도 회전(위에서 본 모습 ) 
Isometric = "equal measure" (같은 측정)을 의미 
현재의 수학공식을 이것을 의미
x_screen = (x - y) * cos(30°)
y_screen = (x + y) * sin(30°) - z

// 또는 더 정확하게:
x_screen = (x - y) * √3/2
y_screen = (x + y) * 0.5 - z

< 2 True isometric 회전행렬  > 

1. Y축 45도 회전:
   [cos(45°)   0   sin(45°) ]   [√2/2   0   √2/2]
   [   0       1      0     ] = [  0    1     0  ]
   [-sin(45°)  0   cos(45°) ]   [-√2/2  0   √2/2]

2. X축 arctan(1/√2) ≈ 35.264도 회전:
   [1      0           0        ]   [1    0       0    ]
   [0   cos(α)    -sin(α)       ] = [0   √3/3   -√6/3 ]
   [0   sin(α)     cos(α)       ]   [0   √6/3    √3/3 ]

최종 투영: (x, y, z) → (screen_x, screen_y)


< 3. Dimetric 투영 > 
Dimetric은 두 축의 단축비가 같고, 하나만 다른 투영입니다.
일반적인 2:1 Dimetric
Y축 회전: 26.565도 (arctan(1/2))
X축 회전: arcsin(1/√5) ≈ 26.565도

x_screen = x - y/2
y_screen = z + (x + y)/4
